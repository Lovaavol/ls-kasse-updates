# LS-Kasse – Updates

Hier liegen nur die Installationsdateien der LS-Kasse (Lieferdienst Solution), kein Programmcode.
Die Kassen holen ihre Updates automatisch aus den Releases dieses Repositorys.

- Kanal **Stabil**: Release mit Tag `stabil/win`
- Kanal **Pilot**: Release mit Tag `pilot/win`

Jedes Release enthält `latest.yml` und die Setup-Datei `LS-Kasse-Setup-<Version>.exe`.
